Kimi Code Monitor 快速上手
操作
授权
未授权时点状态栏完成一次设备授权；换账户点工具栏扩展图标
Mini 模式
点击面板最底部一行收起/展开；底部放哪些模块可自己配
标题行
状态灯与余额；点余额开充值页（可改跳控制台）
模块化
长按面板任意位置进入编辑模式，把模块拖到不同区域就能改变显示方式；点 ≡ 调宽度和专属设置
拖到这 = 隐藏 拖到这 = 展开时显示 拖到这 = 固定显示（Mini 保留）
模块
输入
会话累计输入 token（含缓存）
输出
会话累计输出 token
缓存命中
输入命中 KV 缓存的比例，越高越省
速度
生成速度 tok/s，小字是上轮耗时
上轮耗时
每轮回复总耗时
消耗量
按天统计（7d / 30d），主/子代理拆分
5h / 本周额度
占用进度 + 重置倒计时 + 匀速参照线
宠物
空闲显示时间、工作自动计时（不打断）；点小球播动画，还可设置跳转控制台或充值页

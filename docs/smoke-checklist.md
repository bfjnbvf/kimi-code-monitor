# 重构期人工冒烟清单

目的：重构每一步改动后，确认用户可见行为零变化。每条只需几十秒，全量约 10 分钟。
前置：`chrome://extensions` 重新加载扩展，然后**手动刷新** Kimi Code Web 页面。

## 面板与模块

- [ ] 页面加载后，侧边栏出现面板（标题行 + 各模块），无控制台报错
- [ ] Mini 模式点击底部区域可收起/展开，展开后完整模式内容正确
- [ ] 长按模块进入编辑模式，可拖拽排序、跨三个区域拖动，退出后布局被保存
- [ ] 每个模块的 ≡ 菜单可打开，设置项可改且生效
- [ ] 刷新页面后布局与设置保持

## 额度与数据

- [ ] 5h / 本周额度条显示百分比、重置倒计时、灰色参照线
- [ ] 点标题行手动刷新，额度数字会重新拉取
- [ ] 数据位可在六种口径间切换（24h 消耗/输入/输出/缓存命中/速度/余额）
- [ ] 提问一轮：输入/输出/缓存数字增长，状态文字在「思考中/执行中」间切换，耗时计时正常
- [ ] 统计模块拉到整宽后出现折线图，悬停有点位数值

## 连接与韧性

- [ ] 断网 30 秒再恢复：状态变「未连接」后自动恢复，不需手动刷新
- [ ] 连续重连失败达到上限后进入低频探测，不会刷爆控制台
- [ ] 切换会话（侧边栏点另一个会话）：面板数字切换正确，切回时瞬时恢复
- [ ] 重新加载扩展后刷新页面：面板完整恢复，无僵尸宠物/重复面板

## 宠物

- [ ] Rive 小球：空闲呼吸显示时钟，工作时 loading，结束时撒花，点一下有小动作
- [ ] 桌面宠物：悬停打招呼、可拖拽换位、状态随工作节奏变化
- [ ] 宠物 ≡ 菜单可开关桌面宠物、调大小（50%–150%）

## 命名

- [ ] 新会话聊到第 3 轮自动生成标题写回侧边栏
- [ ] 手动改过的会话名不被覆盖
- [ ] 开两个标签页进同一会话，命名只触发一次

## Popup 与授权

- [ ] 工具栏弹窗打开：账户区块、消耗量图表、热力图、导出链接都在
- [ ] 未授权时走一遍设备授权流程，成功后额度显示
- [ ] 「连接本地 CLI」选 sessions 目录，扫描有百分比进度，完成后长期统计解锁
- [ ] 导出统计得到 JSON 文件，不含对话原文
- [ ] 右键扩展图标 → 选项：标签页模式版式正常（不再是一条 260px 窄列）

## 新手引导

- [ ] 清空 `localStorage` 的引导标记后刷新：分步引导出现，可完成可跳过
- [ ] 引导目标模块被隐藏时，气泡不会卡死在旧位置

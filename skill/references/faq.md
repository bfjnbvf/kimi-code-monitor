# 答疑 FAQ

回答时结合 status-dictionary.md 的口径，保持人话。

## 统计口径

**Q：今日消耗的数字是怎么来的？**
两路合成的：安装时从 Kimi Code 自己的会话日志全量扫一遍历史；之后每轮对话的用量实时攒在页面里。同一天两路谁大用谁，不会重复计算。

**Q：为什么数字和我在网页上看到的不完全一样？**
按本地时区的自然日（0 点到 24 点）统计，与其他口径（滚动 24 小时、UTC 日）会有边界差异，属正常。

**Q：输入 tokens 包含什么？**
未缓存输入 + 缓存读取 + 缓存创建三部分之和；缓存命中率 = 缓存读取 ÷ 总输入。

## 更新与数据

**Q：客户端更新后面板没了？**
可能被更新清掉了（面板文件放在客户端资源目录里）。重跑一次这个技能就能恢复：历史会重新扫描补齐，使用期间攒的数据存在客户端自己的存储里，不受影响。

**Q：卸载会丢数据吗？**
卸载只移除显示用的文件。页面里攒的统计数据和布局偏好还在客户端存储里；重新安装会接着用。

**Q：面板上的余额（加油包）怎么不变化？**
标题行余额每 60 秒跟着客户端本地的用量服务自己更新，不用你说话。一直不动
通常是客户端没在运行（或面板没连上它）；确认客户端开着就行。想立刻校验
可以跑一次「刷新余额」——它写的是兜底快照，只在活数据不到位时显示。

**Q：外部账户的数字怎么不变化？**
面板每 60 秒自己从客户端读一次，不用你说话。数字旁边标着「N 分钟前」，
那就是这串数字的抓取时间。一直不动的两种情形：模块被收起了（收起时不抓），
或客户端里那个供应商查不到用量（没开放余额接口 / 没配 key，此时只出现在模块设置里）。

**Q：外部账户里少了一个我已配置的供应商？**
面板只显示查得到用量的。其余的在模块 ≡ 设置里列着并标了原因，等厂商开放或我们适配。

## 显示问题

**Q：额度条有数字但其他都是空的？**
其他数字来自实时事件流，只在对话进行时增长；开一轮对话就有了。一直不动的话让我自检。

**Q：面板上的吉祥物不动了 / 报了个 wasm 警告？**
控制台里 `wasm streaming compile failed … falling back` 是无害警告（有自动降级），不影响显示。吉祥物完全不出来才算问题，让我自检。

**Q：怎么改面板布局/语言/图表范围？**
长按面板进编辑模式（拖动、调大小、收起模块）；模块右上角 ≡ 是各自的设置（图表范围、宠物数据位等）；语言跟随客户端的语言设置。

## 缓存提醒（3.6.0+，默认关闭）

多轮对话会复用之前已经处理过的上下文缓存，减少不必要的额度消耗。对话放置较久后，
缓存可能失效，下次提问就可能要重新处理前面的上下文，消耗更多额度。如果你本来就准备继续对话，
趁缓存仍有效时续上，有机会少消耗一些额度；不必为了保缓存专门发消息。

开启后，计时从最后一次模型请求开始：侧栏会话列表里 25–29 分钟的相对时间会标黄；
29–30 分钟，宠物球变黄/琥珀，显示「对话缓存 / 即将过期 / 预估剩余 / 1:00 倒计时」；
30 分钟或发新消息后恢复常规外观和数据显示。提醒不调用模型，只读时间并改变本地显示。

**风险：30 分钟只是按本机样本估计的经验值，不是官方承诺的缓存有效期。官方可能调整缓存过期时间，提醒仅供参考，不代表缓存一定会命中或失效，也不保证一定节省额度。**

手动开启：长按左下角宠物球进入编辑模式 → 宠物模块右上角 ≡ →「缓存提醒」→ 开启。

用户明确要求「帮我打开缓存提醒」时，Agent 可以在客户端控制台执行以下代码；它会重载客户端，
执行前必须说明并取得同意。无法操作客户端控制台时，给出手动步骤，不修改补丁的默认配置。

```js
const key = 'kimi-statusbar.config';
const stored = await chrome.storage.local.get(key);
const next = stored[key] || {};
next.modules ||= {};
next.modules.pet ||= {};
next.modules.pet.cacheHint = true;
await chrome.storage.local.set({ [key]: next });
location.reload();
```

## 边界与隐私

**Q：它会上传我的数据吗？**
不会。所有读取都发生在本机：客户端内嵌的本地服务 + 本机的会话日志文件；外部账户余额是面板每分钟向供应商官网查的，key 由客户端自己的配置提供，不经过对话。

**Q：需要把外部账户的 key 给你吗？**
不需要。面板直接读客户端「模型设置」里已配的供应商（key 只在面板内存里用一次，不落盘、不进对话）。你在客户端里加新供应商，面板一分钟内自动跟上。

# 答疑 FAQ

回答时结合 status-dictionary.md 的口径，保持人话。

## 统计口径

**Q：今日消耗的数字是怎么来的？**
两路合成的：安装时从 Kimi Code 自己的会话日志全量扫一遍历史；之后每轮对话的用量实时攒在页面里。同一天两路谁大用谁，不会重复计算。

**Q：为什么数字和我在网页上看到的不完全一样？**
按本地时区的自然日（0 点到 24 点）统计，与其他口径（滚动 24 小时、UTC 日）会有边界差异，属正常。

**Q：输入 tokens 包含什么？**
未缓存输入 + 缓存读取 + 缓存创建三部分之和；缓存命中率 = 缓存读取 ÷ 总输入。

## 更新与数据

**Q：客户端更新后面板没了？**
可能被更新清掉了（面板文件放在客户端资源目录里）。重跑一次这个技能就能恢复：历史会重新扫描补齐，使用期间攒的数据存在客户端自己的存储里，不受影响。

**Q：卸载会丢数据吗？**
卸载只移除显示用的文件。页面里攒的统计数据和布局偏好还在客户端存储里；重新安装会接着用。

**Q：外部账户的数字怎么不变化？**
那是上次刷新时的快照（面板上有「截至」时间）。想更新就说一声，我来刷。

## 显示问题

**Q：额度条有数字但其他都是空的？**
其他数字来自实时事件流，只在对话进行时增长；开一轮对话就有了。一直不动的话让我自检。

**Q：面板上的吉祥物不动了 / 报了个 wasm 警告？**
控制台里 `wasm streaming compile failed … falling back` 是无害警告（有自动降级），不影响显示。吉祥物完全不出来才算问题，让我自检。

**Q：怎么改面板布局/语言/图表范围？**
长按面板进编辑模式（拖动、调大小、收起模块）；模块右上角 ≡ 是各自的设置（图表范围、宠物数据位等）；语言跟随客户端的语言设置。

## 边界与隐私

**Q：它会上传我的数据吗？**
不会。所有读取都发生在本机：客户端内嵌的本地服务 + 本机的会话日志文件；外部账户余额也只在你要刷新时向你指定的平台官网发起查询。

**Q：为什么需要我的 API key？显示余额用。**
key 只在刷新余额的那一次请求里使用，不保存、不显示给任何人（包括不回显给你自己）。建议用可随时轮换的 key。

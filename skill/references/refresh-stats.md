# 刷新本地统计

面板里的「今日消耗 / 按天图表 / 代理明细」来自本机会话日志的扫描结果，安装补丁时会预填一次。之后你在客户端里继续对话，那部分不会自动进文件——**刷新一次就补上**，面板 30 秒内自己更新（不需要重装补丁、不需要重载客户端）。

## 什么时候刷新

- 用户问「面板上的数字怎么不涨 / 今天用了多少，面板显示的好像不对」
- 刚做完一段长对话，用户想知道这一段到底花了多少
- 用户重装了补丁或更新了技能，想确认本地统计在不在
- 用户切到某个旧对话发现没数字——**这条不靠刷新解决**，见本文件末尾

## 怎么做

一条命令（技能自带脚本，自己找客户端位置）：

```
node <技能目录>/scripts/refresh-stats.mjs
```

客户端装在非默认位置时加 `--app <客户端目录>`（和安装器同一个参数）。

成功输出形如：

```
[scan] 文件 851 · 记录 40668 · 天数 63（2026-06-27 ~ 2026-09-21） · 会话 200 · 耗时 2.4s
[refresh] 本地统计已刷新（8371 → 118275 字节），面板最多 30 秒后自动跟上
```

**对用户怎么说**：不说「扫描 wire.jsonl」「重扫索引」，说「我把本地用量重新统计了一遍，面板等几十秒就会跟上」。

## 失败怎么办

| 现象 | 含义 | 怎么说 / 怎么做 |
|---|---|---|
| 退出码 1，提示未找到补丁 | 客户端里没有 `desktop-dist/kcm/scan.mjs`（补丁没装或被客户端更新清掉了） | 先按 install.md 装/重装补丁 |
| 退出码 1，提示扫描失败 | 扫描中途报错，旧文件原样保留 | 原样上报报错，不要自由发挥 |
| 退出码 2，提示没有会话日志目录 | 本机还没跑过 Kimi Code | 说明「还没有可统计的对话记录」 |

## 两条边界（别搞混）

- **刷新只管「按天/按会话的统计底数」**，不会改面板上正在跑的这轮对话的实时数字——那是实时事件在记。
- **切到旧对话仍是空白**，说明的是「本机扫描结果里没有这个会话」（或补丁版本太老没带按会话汇总）。刷新一次再看；还空就按 doctor.md 自检，把结论报给用户，不要反复刷新。

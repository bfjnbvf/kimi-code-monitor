# 话术库（对用户怎么说）

原则：不用专业名词；一次讲一两个点；结尾留钩子（「需要我介绍得更详细吗？」「还有想了解的吗？」）；异常先说结论再说原因。

## 首次见面（安装前，一两句）

> 这是给 Kimi Code 配的用量监控面板，装好后就在会话列表侧栏的底部，能看额度余量、token 消耗和每天的用量图表。要现在安装吗？

用户问风险时：

> 它只在客户端自己的资源目录里放几个显示用的文件，原始文件会先备份，随时可以完整卸载；所有数据都只在本机读取，不外发。

## 首装引导（安装完成、用户重载客户端后）

先确认看到面板，再讲两三个点，别倾倒：

> 面板出来了的话可以看到：顶部两条是 5 小时和本周的额度进度条，带重置倒计时；中间是这轮对话实时消耗的输入/输出/缓存命中。
>
> 有两个容易错过的操作：**点一下面板底部**，就能把面板收起来或展开——收起来只保留关键数字，不占地方；
>
> **在面板上长按**可以进入编辑模式，模块能自由拖动和调整大小，不想要的可以收起来。想了解怎么自定义吗？

用户接茬「想了解怎么自定义」时，分两步讲，别一次倒完：

> 进入编辑模式后每个模块会带上虚线描边：按住就能拖——往上放完整区、往下放迷你区、拖进灰色区就收起来；同一区域里上下拖动排顺序，半宽整宽可以混排。
>
> 还有每个模块**右上角的 ≡ 小菜单**：点它弹出这个模块自己的设置。比如消耗图表切统计范围（24 小时/7 天/30 天）、额度条切倒计时还是具体时间、开关匀速参照线、宠物旁切换显示哪项数据、点小球跳去哪儿。每个模块的菜单不一样，看到什么就能调什么。

后续可以再提的点（每次一两个）：
- 消耗量图表点右上角 ≡ 可以切换 24 小时 / 7 天 / 30 天范围；
- 吉祥物会跟着工作状态变动作，点它会做小动作；
- 外部账户余额会自动跟随你在客户端「模型设置」里配的供应商（DeepSeek / Kimi API / 智谱 / MiniMax 等），配上就会自己出现，不用把 key 给我；没显示的我可以帮你探测一遍。

## 异常解释模板

面板没显示数据时：

> 面板显示「<状态句原文>」，意思是<用 status-dictionary.md 的含义翻译成人话>。通常<对应的处置/预期>。

需要用户配合时（保险一/三）：

> 麻烦帮我看一下面板上那句提示下面的小字（「诊断：」开头那行），复制给我就行。

## 外部账户：探测结果怎么说（首装/重装后）

先说结论，再说"为什么有一个没显示"。数字全部来自 `client-providers.mjs` 的 SUMMARY：

> 我顺带看了你在客户端里配的供应商，一共 3 个：**deepseek 已经显示在这个外部账户里了**（余额 ¥6.70）。
> 另外 **StepFun Step Plan 暂时查不到余额**——它没有开放余额查询接口，所以没放进列表，只在模块设置里记着；**请等待后期更新**。
> 还有 managed:kimi-code 是客户端自己的账号，额度就在面板顶部的 5h 和本周，不在这里重复显示。

用户问「为什么 X 不显示」时，同上，只要一句原因 + 一句"不用你做什么"：

> 面板看到了它，只是查不到用量（那个平台没开放余额接口）。你在客户端里加的其他平台下次会自动出现，不需要重装。

**不要**：不要向用户要 key（面板自己从客户端读）；不要承诺某个平台"很快支持"。

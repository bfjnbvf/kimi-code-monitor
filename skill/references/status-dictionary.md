# 状态字典（面板在说什么）

面板数据不到位时，消耗量模块位置会出现一句**状态句**（人话）和一行「诊断：」开头的**技术串**（六段）。状态句给用户看，技术串给你看。

## 状态句（按等级）

| 状态句 | 含义 | 常见原因 |
|---|---|---|
| 正在加载数据统计… | 刚启动，数据在路上 | 重载后几秒内，等一等就好 |
| 暂无历史数据，从现在开始统计 | 管道健康，只是没有历史 | 全新机器首次安装（正常）；或历史预填被跳过 |
| 本地服务连接中，正在重试… | 与客户端内嵌服务的连接断了 | 客户端正在重启、端口切换中 |
| 连接本地服务失败，正在自动重试 | 断开超过 30 秒 | 客户端未运行 / 接口变动 |
| 数据显示异常，可让 Kimi 帮忙自检 | 渲染层出了错 | 需要看 Console 报错（doctor.md 第二层） |

窄位（吉祥物旁的数字位、图表汇总位）只显示短词：统计中… / 连接中… / 异常，与上表同源。

## 诊断串六段

格式：`路径 … · kap 已知/未知 · 数据 … · WS … · 焦点 … · 桥 …`

| 段 | 值 | 含义与处置 |
|---|---|---|
| 路径 | 含 `/sessions/…` | 会话焦点正常；若显示 `/` 或其他 → 客户端不在会话页（切到某个对话再看） |
| kap | 已知 | 找到了本地服务地址 |
| | 未知 | 地址没解析出来（刚重载/服务重启中）；持续未知 → 客户端版本可能变了接口约定 |
| 数据 | 已载入 | 历史数据文件读取成功 |
| | 载入中 | 还没读到 |
| | 无历史 | 文件缺席（全新环境正常，或预填被跳过） |
| | 加载失败 | 文件在但读不了 → 重装 |
| WS | open | 实时事件流已连接（实时数字应随对话增长） |
| | connecting / init | 连接中 |
| | closed(rN) | 断开，第 N 次重试 |
| | 等kap源 | 在等服务地址解析 |
| 焦点 | session_… | 已锁定当前会话 |
| | 无 | 不在任何会话页 |
| 桥 | OK | 历史数据已进渲染层（此时锁应已消失） |
| | ？ | 数据还没送达渲染层 |
| | 异常 | 渲染层处理出错 → 要看 Console 报错 |

## 组合判读示例

- `kap 未知 · WS 等kap源` → 地址解析链断了：确认客户端是否刚重启；持续如此收集信息上报。
- `数据 已载入 · 桥 ？` → 文件读到了但没送进渲染（时序或渲染异常）：等一轮轮询（30 秒内）；持续 → Console。
- `WS open · 焦点 无` → 事件流通了，只是用户不在会话页：切到对话即可。
